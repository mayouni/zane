Approach · for people who already practise UX, or build with a framework, and ask what this adds

The comparison places Zane beside the practices, frameworks and languages a team already uses, and not instead of them.

The comparison sets Zane beside seven established practices, four UI frameworks and five description languages, so that a reader can see what Zane takes from each and what it adds. The comparison lets a reader see where each practice or tool stops, as its own published pages describe it. It is made on two pages, and each page is a table of claims with sources. Each row says what Zane takes from the practice or the tool and what it adds, and each page says what it did not read.

The claim the comparison makes, and the limits of its sources

Practices for judging an interface after it exists are well established, and so are the frameworks and languages for building or describing one. The pages listed here were read on 4 November 2026, and none of them gives an account of what an interface must let a user, a person or an agent, do across a set of channels, such that a machine can refuse a declaration for lacking it before the interface exists.

Zane offers such an account: six things a user does, across 10 channels, with the law's 123 rules placed on the cells and the empty cells drawn empty on the grid page.

This claim is a statement about the sources below, and not about the whole field: other work may exist that this reading did not find. It is also a structural claim, and its only evidence is this repository: there is no study, no user and no foreign application run end to end. A reader who knows of a practice, a framework or a language that already does this is asked to report it.

What the comparison does not decide, and how a row is corrected

The comparison does not say that Zane is better. It says where each practice, framework and language stops, as each describes itself, and where a declaration, a law held as data and a suite add a different kind of thing. Each team decides whether that is useful to it, and no study provides evidence for that usefulness.

A row that over-reads its source is corrected from that source, and each page names what it read and how far.
