The claim, and what bounds it

Practices for judging an interface after it exists are well established, and so are the frameworks and languages for building or describing one. In the pages listed here, read on 4 November 2026, we found no account of what an interface must let a person do, across a set of channels, that a machine can refuse a declaration for lacking before the interface exists.

Zane offers one: six things a person does, across 10 channels, with the law's 123 rules placed on the cells and the empty cells drawn empty (the grid).

That is a statement about the sources below, not about the field. Other work may exist that we did not find. It is also a structural claim, and its evidence is this repository: there is no study, no user and no foreign application run end to end. A reader who knows of a practice, a framework or a language that already does this is asked to say so.

What the comparison does not decide

It does not say Zane is better. It says where each practice, framework and language stops, as each describes itself, and where a declaration, a law as data and a suite add a different kind of thing. Whether that is useful to a team is for the team, and the evidence for it is not a study.

A row that over-reads its source should be corrected from the source; each page names what it read and how far.
