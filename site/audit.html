Try · things to run, watch and measure

The Try section offers three ways to try Zane without reading the theory first.

The Try section gathers three things to run or watch, so that a person can try Zane on real pages before reading the theory. It lets a person present Zane to a team, run the audit on a page, or see what a screenshot can and cannot decide. Each way states what it shows and what it does not.

Three ways to try Zane, each with what it shows

The tour, a presentation of Zane in scenes

The tour shows full-screen scenes in an order chosen for the person in the room: a UX designer, a product designer, a programmer, an AI builder or a decision maker.

The tour →

The UI audit, which measures a painted page

The UI audit measures what a browser paints on any page that you can serve beside it, and it cites the rule for every finding.

UI audit →

The screenshot audit, for an application you do not own

The screenshot audit is for an application that nobody here owns. It reduces a screenshot to facts and judges them on the three rules that a screenshot can decide.

Screenshots →

The wasm proof, in the same band, runs the conformance suite through the verifier compiled to WebAssembly in your browser, and the Build page has a box to check a declaration of your own the same way.

A single file that carries the verifier and a local server, and that needs no Node, is built from this repository with Zig (zane serve, in the binary's design), and it has not been released. The file will appear on this page when it is released.
