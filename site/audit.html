Try · things to run, watch and measure

The Try section offers four ways to try Zane without reading the theory first.

The Try section gathers four things to run or watch, so that a person can try Zane on real pages before reading the theory. It lets a person present Zane to a team, run the audit on a page, see what a screenshot can and cannot decide, or read one real run on a real site. Each way states what it shows and what it does not.
