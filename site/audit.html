Run it on an interface and see what it finds

The audit measures what an interface actually paints, not what its source declares: computed size, true contrast, the trail, the room a block has, and the menu against the tree.

The UI audit

It runs in a browser on any same-origin interface and reports, for each finding, the rule it rests on. It measures Rules 105, 107, 108, 114, 115 and 116. Open the UI audit.

A colour it cannot read is reported as not decided, naming the colour, and never skipped.
