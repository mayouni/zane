Try · for anyone who wants to see what an afternoon buys

One real run on a real site, in under an hour, and an honest result.

The subject is Zing's own site, a framework in the same family and a site this project reads and does not own. The whole run, from the first declaration to the last audit, took forty-seven minutes on 5 November 2026, including mending a tool along the way. It found one thing, and that one is not a defect.

1 · Declare three surfaces

The main menu, the style select and the landing page, written in the language from the markup, by hand: examples/quick-win/zing-landing.zui. Its header says it is StzZui's description of pages it does not own. The part that matters:

DEFINE INTERACTION style_select (
  SATISFIES [SELECT],
  ALWAYS_REACHABLE [UNDO, CANCEL],
  ROLE navigate,
  ACTOR reader
)

2 · Run the verifier

$ node tools/zui/cli.js check examples/quick-win/zing-landing.zui
clean — 1 file(s), 0 violations at level 2 against Zui v3.13

Clean. A style switch that changes how the page looks, and nothing that is true, is a selection with a navigating role, which is how Zing built it.

3 · Audit the ten pages

Zing's site was served read only beside the audit with serve-beside.js, and the audit run on its front page and its nine pages under site/, in the default mode and in Zing's own default style. It reported one finding: the page at site/index.html has no trail and no bar marking it. That page is a redirect to the front page, marked not to be indexed, with one sentence in it. No reader stays on it, so the finding is the audit measuring a page that is not one. Every page a reader reads was clean.

A tool was mended on the way, and that is part of the result. The first version of the serving script put the audit's own files under /site/, which shadowed Zing's own site/ folder. It now serves the audit at /__zui/ui-audit.html, a path no site uses, and it is the version the web case's page links.

4 · What it shows, and what it does not

  • The surface was already lawful under what these checks can see. That is a result: an hour shows a team where it stands, and here it stands well. Zing's own page says it obeys the law it advertises, which is the likely reason.
  • For contrast: on the Softanza site, the web case found four real findings in the same kind of run.
  • Not run: Zing's other style. The audit's style switch drives this site's styles, and Zing keeps its own choice under its own name, so only Zing's default was measured.
  • Nobody looked: no person has judged these pages for this run; the audit measures size, contrast and the path, not whether the page is good.
