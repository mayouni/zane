# zane 0.1.0

The first release of `zane`, the Zane verifier and its local server: one file for each system, and one WebAssembly module
for a browser. The commit it is built from is the one the tag `v0.1.0` names, so these notes do not name it.

- **The law:** v3.15, 123 rules (`constitution/rules.json`).
- **The language:** 1.5. **The contract:** v1.9, 37 diagnostics (`conformance/violations.json`).
- **Conformance:** level 4, 73 fixtures of 73.
- **The compiler:** Zig 0.15.2. Every file is `ReleaseSmall`. Linux is musl and statically linked.
- **How it is built:** `zig build release`, which writes `zig-out/release/` and runs no other program. Its gate is two
  clean builds in two fresh clones, each with its own empty caches, giving the same `SHA256SUMS`.

`zane --version` prints `zane 0.1.0`. It names no commit, because the tag does.

## The files are not signed

No file carries a signature. Windows SmartScreen may warn before it runs `zane-0.1.0-x86_64-windows.exe`. macOS will refuse
to open a file downloaded from the web until its quarantine is removed. The hash is how to know a file is the one built
here. Compare it with the line for that file in `SHA256SUMS` and in the table above.

**On Windows** (PowerShell), in the folder that holds the file:

```powershell
Get-FileHash .\zane-0.1.0-x86_64-windows.exe -Algorithm SHA256
```

The hash it prints, in capitals, is the same as the one in `SHA256SUMS`. `certutil -hashfile zane-0.1.0-x86_64-windows.exe SHA256`
prints it too.

**On Linux**, with `SHA256SUMS` beside the file:

```bash
sha256sum -c SHA256SUMS --ignore-missing
chmod +x zane-0.1.0-x86_64-linux
```

**On macOS**, with `SHA256SUMS` beside the file:

```bash
shasum -a 256 -c SHA256SUMS --ignore-missing
chmod +x zane-0.1.0-aarch64-macos
xattr -d com.apple.quarantine zane-0.1.0-aarch64-macos
```

Each file you have prints `OK`. A file that prints `FAILED` is not the one built here: do not run it.

## Building it yourself

With Zig 0.15.2, from a clone at the tag `v0.1.0`:

```bash
zig build -j2 release
```

`zig-out/release/SHA256SUMS` is then the same as the one published.
