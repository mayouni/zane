The proof · stage S3 of the binary, in your browser

The wasm proof runs the conformance suite through the verifier compiled to WebAssembly, in this browser.

The wasm proof runs every fixture at every level, 1 to 4, through site/zane.wasm and compares each envelope, byte for byte, with what the native zane binary printed for the same source. It lets a person see, with only a browser, that the two builds of one code print one report. Nothing leaves the page.

The result of the proof in this browser

Loading the wasm and the expected envelopes…

The expected envelopes are written by node tools/zane/parity.js --write-wasm-proof, from the native binary on the same sources, never by hand, with the sha256 of the wasm they were written for. Run without the flag, the parity check fails when the record no longer matches the binary or the wasm, and this page says so when the wasm it loads is another build.

Each fixture's envelope from the wasm beside the native binary's

Each line below is one fixture. Opening it shows the envelope at level 4 from the wasm in this browser beside the one from zane check --json --level 4; a fixture that differs at any level opens at the first level where it differs.

Limit: the proof shows sameness, never rightness. Two builds that agree on every byte share every mistake of the verifier. The generated corpus that tools/zane/parity.js runs against the native binary is not run here.
